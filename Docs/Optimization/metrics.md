# G1~G3 GPU 최적화 측정 기록

## 측정 환경과 조건
- 하드웨어: Intel i9-14900HX, RTX 4060 Laptop(8GB), RAM 32GB, Direct3D12
- Unity 6000.3.22f1 에디터, PC 품질 레벨(`PC_RPAsset`, Forward+)
- Game 뷰 최대화, 1920×1080 고정 해상도, Stats 표시, VSync 꺼짐
- Play 진입 → `GameState.Playing` 이후, 다음 상태로 고정
  - 좀비 스포너 정지, 활성 좀비 비활성화
  - 플레이어 위치 (16.03, 0, -28.06), yaw -25°, pitch 5°
- `ProfilerRecorder`로 10초씩 수집한 매 프레임 평균, 3회 반복 후 평균

## 참고
- 미니맵 카메라만 끄고 잰 상한선(초기 측정이라 Game 뷰가 작음)
  - Main 3.74 → 2.47ms
  - Batches 219 → 188
  - SetPass 94 → 75
  - Shadow casters 434 → 374
- Before 세션 상태 표시줄에 URP 경고가 있었음: "Reduced additional punctual light shadows resolution by 2 to make 9 shadow maps fit in the 2048x2048 shadow atlas". G3 이후 세션에서는 이 경고가 나오지 않음.
- 에디터 측정이라 에디터 루프 오버헤드가 포함된다. GPU 시간이 2ms 수준이라 이 PC에서는 GPU가 병목이 아니고, 그래서 FPS는 CPU 쪽 노이즈의 영향을 크게 받는다.
